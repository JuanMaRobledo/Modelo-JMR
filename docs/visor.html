Valoraciones guardadas

Consulta valoraciones que hayas guardado antes desde este visor — no necesitas volver a subir el Excel. Requiere el mismo token de acceso de GitHub con permiso sobre el repo privado Modelo-JMR-datos, guardado solo en este navegador.

Este visor lee los resultados ya calculados por tu Excel (Modelo JMR); no recalcula el DCF ni los múltiplos por sí mismo. El nombre y el logo se toman de la hoja "Input sheet" y de Financial Modeling Prep respectivamente; el "Precio actual" se consulta en vivo con la misma API key de la Calculadora y la Bitácora — si no hay key o el ticker no se encuentra, se muestra el precio que quedó guardado en el Excel al momento de llenarlo, marcado como tal. Las pestañas "Estados Financieros", "Valoración" y "Análisis" muestran, tal cual, las hojas de tu Excel involucradas en la valoración (no las tablas fijas de referencia de la plantilla — primas de riesgo país, promedios de industria, convertidores, etc. — que son iguales para cualquier empresa). Guardar una valoración la sube como un archivo JSON a un repositorio privado tuyo en GitHub (Modelo-JMR-datos) usando un Personal Access Token que solo tú generas y que se guarda únicamente en este navegador — nunca se envía a ningún servidor propio. Para valorar una empresa nueva sin Excel, usa la Calculadora DCF. Contenido con fines educativos y de organización personal — no constituye asesoría financiera.
